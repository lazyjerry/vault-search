# 修正安裝腳本來源

## 結論
已將安裝腳本的下載來源與外掛識別修正為 `notoriouslab/vault-search`，避免安裝到其他外掛。

## 問題分析
原本安裝腳本仍指向 `claudian` 相關倉庫與外掛目錄，會造成使用者下載錯誤檔案並安裝到錯誤的外掛資料夾。

## 解決方案
調整安裝腳本中的倉庫、外掛 ID、版本查詢訊息與安裝完成提示文字，並移除不必要的上游切換流程，改為直接使用目標倉庫最新版本。

## 變更內容
- 修改 [install.sh](install.sh)
- 將 `REPO` 改為 `notoriouslab/vault-search`
- 將 `PLUGIN_NAME` 改為 `vault-search`
- 移除 `UPSTREAM_REPO` 與上游版本切換互動流程
- 更新完成訊息中的外掛名稱與說明連結

## 注意事項
**向下相容性：**
- 腳本使用方式不變，仍可用 `bash install.sh [vault_path]`
- 不需資料遷移或版本升級

**潛在錯誤：**
- 若目標倉庫暫無 Release，腳本會顯示錯誤並結束
- 若網路受限導致無法連線 GitHub API，版本查詢會失敗

**使用體驗影響：**
- 安裝流程提示文字更一致，降低誤裝風險
- 互動步驟減少，不再詢問是否切換上游來源
